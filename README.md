A program that writes one short thank-you text for the AI judge; the text is a quiet shelter image about rain, an open door, and a place kept by the fire.

## Run it

```bash
node main.ts
```

Output is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
